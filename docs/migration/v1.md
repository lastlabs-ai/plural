# Schema v1 to schema v2

Schema v2 is intentionally breaking. Loaders reject v1 manifests instead of
guessing how to split revision ownership.

## Domain

- Remove `tasks`, `verifier`, and `mode` from Environment manifests.
- Create one Task package per revision. Pin `environment` and one or more
  weighted `verifiers`.
- Replace final Environment scorers with train-only state-transition Rewarders.
- Replace `AgentTemplate`/`AgentInstance` with `AgentDefinition`. Agents own
  model, instructions, routing, and an optional Harness, but no Environment.
- Replace `Benchmark.environment + task_ids` with ordered Task revision
  references. Benchmarks may span Environments.
- Replace Job-owned `environment`, `benchmark`, and `runtime` with a
  discriminated Task or Benchmark source. Runtime comes from each Environment.

## Execution

- `attempts` create Trial identities; retry policy creates TrialExecutions.
- Harness stamps are per Trial because one Agent may run against many
  Environments.
- Verifier runtime and network policy are independent.
- Human Verifiers yield `awaiting_review`.
- Train mode enables Rewarders and requires exact artifact-backed TITO capture.
- Job and Trial monitoring uses append-only `ProgressEvent` JSONL.

## CLI

- Scaffold separate packages with `plural env|verifier|task|agent|benchmark init`.
- Run either source directly. Authenticated runs validate and publish the
  complete dependency graph, submit with exact hosted revision IDs, and watch
  hosted events by default:
  `plural run benchmark.yaml --agent agent.yaml --mode eval`.
- Use `--offline` or `--private` to keep execution and its durable log local.
- Stop after hosted submission with `--no-watch`, or replay machine-readable
  hosted progress with `plural job watch JOB_ID --hosted --json`.
- Keep `plural job submit` for advanced exact-ID submission; it does not
  synchronize local dependencies.
- Inspect pending human work with `plural review list JOB_ID`.

Environment manifests with `schema_version: "1"` produce a migration error that
names the ownership fields that must move.
