# Migrate to the public evaluation API

This release is a clean break for public authoring code.

- `EnvironmentDefinition` → `Environment`
- `EnvironmentRuntime` → `Runtime`
- `AgentDefinition` plus `AgentBinding` → `Agent`
- `TaskDefinition` → `Task`
- `BenchmarkDefinition` → `Benchmark`
- `JobSpec` and source wrappers → `Job`
- `WeightedVerifier` → a Verifier's `weight` field
- `native_actions_v1` / `native_chat_v1` → omit the Harness for native behavior
- Declared-only vendor Harnesses (`hermes`, `claude-code`, `codex`) →
  `Agent(harness="claude-code")` with optional `harness_kwargs`
- Declarative custom `Harness(command=..., source=..., outputs=...)` →
  subclass `Harness`, implement `run(task, agent, environment)`, and attach an
  instance to the Agent

Do not copy `schema_version`, `revision`, bindings, or protocol names into new
public YAML. Use `version`, public constructor fields, and a small object
discriminator where needed.

Before:

```python
spec = JobSpec(
    source=BenchmarkJobSource(benchmark=definition),
    agents=[AgentBinding(agent=agent_definition)],
)
```

After:

```python
job = Job(benchmark, agents=[agent])
```

For Python `@action` environments, replace manual compilation, action rebuilding,
and package source construction with:

```python
environment = World(runtime=runtime)
```

Regenerate YAML with `plural export project.py:job --output job.yaml`. Older
schema manifests are not silently guessed because ownership and defaults may
have changed.
