# 0.8 to 0.9 break

Package version is **0.9.0**. There is no compatibility window.

## Domain

- `EnvironmentCommand` and `AgentSpec` are deleted.
- `@tool` is `@action`. `Environment.tools` is `Environment.actions`.
- Container, network, and resources moved from `JobSpec` onto
  `EnvironmentRuntime`.
- `AgentTemplate.harness` is optional. `None` is the native path.
- Harness stamps (`HarnessStamp`, `resolve_harness_stamp`) are required
  when a harness is bound.

## Execution

- Defaults: `network=none`, local excluded.
- `resolve_effective_policy()` is the only preflight decision point.
- Declared harnesses cannot run.
- Trace schema is **2.0.0**. `Decision` is `Turn`. `ToolCallStep` is
  `ActionStep`. `_migrate_legacy_trace` is deleted.

## Hosted data

Plural domain tables are dropped and recreated. Users, accounts,
organizations, projects, API keys, and credit-ledger balances are
preserved.

## CLI

- `plural env action|resource|capabilities`
- `plural env harness stamp|unstamp|list|capabilities`
- `plural runtime doctor --env`
- `plural agent template` and `plural agent instance`
